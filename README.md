# 🚀 Fluxbit

Fluxbit is a modern cryptocurrency dashboard built with React that displays real-time market data using the CoinGecko API. It features a clean, responsive UI inspired by trading platforms, with smooth horizontal scrolling card layouts and dynamic loading states.

## ✨ Features

- 📊 Real-time cryptocurrency prices
- 🔄 Live market data via CoinGecko API
- 📱 Fully responsive design (mobile & desktop)
- 🎴 Horizontal scroll-based card layout
- ⚡ Smooth loading system
- 🎨 Clean UI inspired by crypto trading platforms

## 🛠 Tech Stack

- React.js
- Axios
- CSS Grid & Flexbox
- CoinGecko API

## 📦 Installation

```bash
git clone https://github.com/T3ZZ4R/Fluxbit.git
cd Fluxbit
npm install
